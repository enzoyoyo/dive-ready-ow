# Local media (not committed)

This folder is intentionally empty in the public template. Add only videos, posters and frame images that you created or are licensed to use.

1. Use short, stable file names such as `demo-breathing.mp4` and `demo-breathing-poster.jpg`.
2. Remove EXIF/GPS metadata and any faces, voices, overlays or documents that you do not have permission to publish.
3. Compress for the device you target, then check that the file remains legible and that the audio stream decodes.
4. Reference the local file names from `Resources/StudyCatalog.json` and keep the source, time range and safety boundary accurate.
5. Keep this folder local. The `.gitignore` rule tracks only this README, so personal media will not be added accidentally.

Media filenames are not proof of ownership. Keep the license or permission record outside this repository.
